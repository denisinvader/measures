# Measures

A tool for measuring the dimensions, spacing, and distances between elements on any website.

This package is supposed to be used through [UNPKG](https://unpkg.com/) or [jsDelivr](https://www.jsdelivr.com/).

## Usage

Add bookmark script:

```js
javascript:(()=>{const s=document.createElement('script');s.src='https://unpkg.com/@dinvader/measures';s.defer=true;document.head.appendChild(s)})();
```

Or include package directly in your website source code.
